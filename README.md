# Контекст — персональная бизнес-лента

Локальный прототип на Django. Главная страница: лента из 6 демонстрационных событий, редактируемый профиль компании, расчёты последствий, фильтры, поиск, сохранённые новости и раскрываемые рекомендации.

## Запуск в PowerShell из корня проекта

```powershell
.\nvenv\Scripts\python.exe .\alphaproj\manage.py migrate
.\nvenv\Scripts\python.exe .\alphaproj\manage.py runserver
```

Открыть http://127.0.0.1:8000/ . Существующая форма регистрации доступна по /v1/register/; она остаётся демонстрационной.

Для нового окружения: Python 3.12+ и `pip install -r requirements.txt`.

## Проверка

```powershell
.\nvenv\Scripts\python.exe .\alphaproj\manage.py check
.\nvenv\Scripts\python.exe .\alphaproj\manage.py test alphamain
node --check .\alphaproj\alphamain\static\alphamain\feed.js
```

## Границы прототипа

Новости вымышлены, не загружаются из СМИ. Разбор работает по прозрачным сценарным правилам, без настоящей языковой модели. Профиль и избранное хранятся в localStorage текущего браузера; серверной авторизации и синхронизации нет. Текущая ставка ЦБ не проверяется: 14% — условие учебного сценария.

Кредит: неизменный остаток × (14% + надбавка); для фиксированной ставки вывод отличается. Металл: месячные закупки × 8%. Импорт: полная стоимость месячного импорта × 6%. Программа поддержки: условные 5%, без утверждения о существовании такой программы.

Для следующего этапа: серверные модели компании/новости/анализа, авторизация с разделением данных пользователей, источник новостей с датами и ссылками, серверная интеграция LLM с ключом в переменной окружения. Проект настроен для локальной разработки, не для публичного развёртывания.
